# E-Commerce Management System (C++)

# Project Overview
This is a console-based E-Commerce Management System developed in C++.  
It allows users to browse products, manage accounts, and simulate online shopping operations.

This project demonstrates core programming concepts such as file handling, loops, conditions, and user management.

---

# Features

# User Features
- User registration and login system
- View available products
- Purchase products
- View order history

# Admin Features
- Add new products
- Update product details
- Remove products
- Manage system data


# Technologies Used
- C++
- File Handling (txt/csv)
- Console Application
